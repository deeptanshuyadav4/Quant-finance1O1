# 📊 Quant Finance Starter

This repository contains my initial projects in quantitative finance, focusing on data analysis, visualization, and basic trading strategy development using Python.

---

## 🚀 Project Overview

The goal of this project is to build a strong foundation in financial data analysis and algorithmic thinking by working with real-world stock market data.

---

## 🧠 What This Project Covers

* 📈 Stock price data analysis
* 📊 Moving averages and returns calculation
* 📉 Data visualization using graphs
* 🤖 Basic trading strategy (Moving Average Strategy)
* 🔁 Simple backtesting of strategies

---

## 🛠️ Tech Stack

* Python
* Pandas
* Matplotlib

---

## 📂 Project Structure

* `data/` → Stock market datasets
* `notebooks/` → Jupyter notebooks for analysis
* `scripts/` → Python scripts
* `images/` → Output graphs and visualizations

---

## 📊 Sample Strategy

A simple moving average strategy:

* Buy when price crosses above moving average
* Sell when price crosses below moving average
